# Evaluation Metrics Extraction

This module extracts real evaluation metrics from FluSight hub HTML reports for use in model card generation.

## Overview

The module parses HTML evaluation reports generated by the FluSight hub to extract:
- Weighted Interval Scores (WIS)
- Mean Absolute Error (MAE)
- Coverage metrics (50% and 95% prediction intervals)
- Model rankings across all metrics

## Modules

### `html_parser.py`

Parses HTML evaluation reports to extract model performance data.

**Functions:**
- `parse_wis_report(html_path)` - Extracts metrics from WIS evaluation HTML
- `parse_all_wis_horizons(reports_dir)` - Parses multiple reports

**Returns:** pandas DataFrame with model names as index and metrics as columns

### `metrics_extractor.py`

Extracts and structures metrics for specific models.

**Functions:**
- `extract_model_metrics(model_name, html_path)` - Gets metrics for one model
- `get_model_rankings(html_path)` - Gets rankings for all models

**Returns:** Dictionary with structured metrics suitable for model card generation

## Usage

### Extract Metrics for a Model

```python
from evaluation import extract_model_metrics

# Extract metrics for UMass-flusion
metrics = extract_model_metrics(
    model_name='UMass-flusion',
    html_path='path/to/report.html'
)

print(f"Overall Rank: {metrics['overall_rank']} / {metrics['total_models']}")
print(f"WIS: {metrics['metrics']['WIS']['value']}")
print(f"95% Coverage: {metrics['metrics']['95% Coverage']['value']}")
```

### Parse HTML Report

```python
from evaluation import parse_wis_report

# Parse report into DataFrame
df = parse_wis_report('path/to/report.html')

# View top models
print(df.sort_values('rank').head(10))

# View UMass models
umass_models = df[df.index.str.contains('UMass')]
print(umass_models[['rank', 'absolute_wis', 'coverage_95pct']])
```

### DataFrame Columns

- `model` - Model name (index)
- `rank` - Overall rank (lower is better)
- `absolute_wis` - Weighted Interval Score
- `relative_wis` - Relative WIS compared to baseline
- `log_relative_wis` - Log-scale relative WIS
- `mae` - Mean Absolute Error
- `coverage_50pct` - Coverage of 50% prediction intervals (%)
- `coverage_95pct` - Coverage of 95% prediction intervals (%)
- `n_forecasts` - Number of forecasts submitted
- `pct_forecasts` - Percentage of possible forecasts submitted
- `n_locations` - Number of locations submitted
- `pct_locations` - Percentage of possible locations submitted

## HTML Report Structure

The FluSight evaluation reports are R Markdown HTML files containing:

1. **Embedded JSON data** in `<script type="application/json">` tags
2. **Interactive tables** with model performance metrics
3. **Multiple evaluation periods:** Last 2, 4, 8 forecasts, and long-term

The parser extracts data from the first table (aggregate metrics across all evaluation periods).

## Notes

- The parser expects FluSight-style HTML reports
- Rankings are calculated within the parser (lower rank = better performance)
- Coverage rankings are inverted (higher coverage = better = lower rank number)
- WIS and MAE rankings follow normal convention (lower value = better = lower rank)
